## Notes

* **Text length** refers to the observed character-length range of the corresponding field.
* `—` indicates that the dataset does not provide a relevant classification label.
* The **ERI Engineering** dataset contains both broad engineering fields and more fine-grained engineering subdomains.
* The **LMSYS** datasets contain multi-turn conversations. For classification purposes, user messages can be extracted from the conversation structure rather than using the complete conversation.
* Dataset suitability should be evaluated based on **text quality, domain relevance, label availability, text length, and whether the text represents realistic human queries/conversations**.
